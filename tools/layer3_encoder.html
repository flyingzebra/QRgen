Reed–Solomon error correction and interleaving

Transform the complete Layer 2 data codewords into QR error-corrected, interleaved message bits. Explore RS blocks, parity bytes, and remainder bits. Entirely offline, in one HTML file.

Paste the JSON export below, or choose a file.

The binary file contains data codewords, not an encoded QR image. Set the matching version/ECC level.

5. Interleaving order

    
Take data byte 0 of every block, then data byte 1, and so on; longer blocks contribute one additional data byte. Then interleave parity bytes independently. No parity is calculated over the interleaved sequence.

6. Layer 3 output → Layer 4 / 5

    
Layer 3 finishes with a complete interleaved sequence of data and ECC bytes, plus 0–7 zero remainder bits. Layer 4 reserves the function-pattern modules; Layer 5 places these bits into the matrix.

JSON contract and traceability
      
Exports qrgen.layer3.v1. Contains version, ecc, blocks, interleavedData, interleavedEcc, interleavedCodewords, remainderBits, and finalBitstream. The original Layer 2 JSON is preserved when imported, allowing later layers to trace the complete pipeline.

This is a stand-alone browser tool with no external dependencies and no online requests. It encodes parity but does not implement RS decoding or QR matrix rendering. Follow ISO/IEC 18004 for formal conformance.
