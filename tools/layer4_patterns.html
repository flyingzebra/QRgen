2. Function-pattern rules

    
Finder: 3 × 7×7Separator: whiteTiming: row/column 6Alignment: 5×5Format: 2 × 15Version: 2 × 18 (v≥7)

    
Each function cell has a reservation flag independent of its color. A light finder separator, for example, is reserved just like a black finder module.

    
The format and version fields are reserved but not populated; their BCH-protected values are determined in Layer 7. The single permanent dark module is at (8, N − 8).

    
Alignment targets are placed using version-specific centres, skipping the three finder corners. Where an alignment target crosses the timing line, the alignment modules take precedence.

    
Scope: Layer 4 does not place Layer 3 data/ECC bits, apply a mask, or write BCH bits. Those belong to later layers.

6. Export for Layer 5

  
The qrgen.layer4.v1 JSON contains modules[y][x] (0, 1 or null), reserved[y][x] (boolean), kinds[y][x] (category), and optional imported layer3 data. A null function module represents a reserved format/version placeholder; a null data module represents an unfilled encoding position.
