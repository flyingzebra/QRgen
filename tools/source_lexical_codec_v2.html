Modes: English sentences encodes each 42-bit block using a fixed grammatical template: article + adjective + singular noun + adverb + third-person transitive verb + article + adjective + singular noun. Articles vary in a predictable four-sentence cycle. These are valid sentence structures but not a coherent narrative. Compact words (v1) uses the canonical 2,048-word BIP-39 list with 11 bits per word and can decode text from the original version. Both modes use the same 17-byte frame, original byte length, and CRC-32. Neither mode encrypts or hides content cryptographically. Compression selects the smallest of gzip, JavaScript LZSS, and raw. Original uploaded file bytes are preserved.
